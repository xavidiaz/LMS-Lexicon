# Definition of Done #

En User Story/Sub-issue är Done när:

- [ ] Acceptance Criteria är uppfyllda
- [ ] Lösningen bygger utan fel och kan startas
- [ ] Nödvändig server-side validering och authorization finns
- [ ] Eventuella databasändringar har en fungerande migration
- [ ] API-anrop följer BFF/YARP-flödet
- [ ] Funktionen är testad och verifierad
- [ ] Pull Request är granskad av minst en annan gruppmedlem
- [ ] Review-kommentarer är åtgärdade
- [ ] Ändringen är mergad till development
- [ ] Berörda Sub-issues är stängda
- [ ] README är uppdaterad om ändringen påverkar hur projektet installeras, körs, konfigureras eller testas
